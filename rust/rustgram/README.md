# rustgram: ранний экспериментальный клиент

Отдельная основа нового клиента на Rust. Сейчас реализованы вход по номеру,
коду и при необходимости двухэтапному паролю, вывод до 20 чатов и чтение
последних сообщений выбранного чата. Это не
готовая замена Forkgram: GUI, отправка сообщений, вложения и другие функции отсутствуют,
а реальный вход и взаимодействие с Telegram ещё не проверены.

Telegram API и MTProto предоставляет `grammers` на Rust. Для сохранения сессии
используется SQLite через `libsql`, который включает нативную библиотеку на C;
проект пока не состоит исключительно из Rust-кода.

## Запуск

Нужны собственные Telegram API ID и API hash (см.
[Telegram API development tools](https://core.telegram.org/api/obtaining_api_id)).
Передайте их через переменные `RUSTGRAM_API_ID` и `RUSTGRAM_API_HASH`, затем:

```sh
cargo run --manifest-path rust/rustgram/Cargo.toml --bin rustgram -- dialogs
cargo run --manifest-path rust/rustgram/Cargo.toml --bin rustgram -- history CHAT_ID 20
```

`CHAT_ID` берётся из списка диалогов; лимит истории от 1 до 100.
Сообщения выводятся в терминал, поэтому они могут сохраниться в его истории.

Вводите номер, код и пароль только в терминале программы, никому их не
передавайте. Создаётся новая авторизованная сессия Telegram; Forkgram не
изменяется. Файл сессии расположен в `$XDG_DATA_HOME/rustgram/session.sqlite3`
или `~/.local/share/rustgram/session.sqlite3` и содержит данные доступа к
аккаунту без дополнительного шифрования. Программа требует закрытые права
каталога и файла; не делитесь ими и не добавляйте их в Git. Для отзыва доступа
используйте список активных сеансов Telegram. Удаление локальной копии файла
само по себе не отзывает удалённую авторизацию.

Офлайн-проверка: `cargo test --manifest-path rust/rustgram/Cargo.toml`.

## Экспериментальное окно

При тех же переменных окружения графическую версию можно запустить так:

```sh
cargo run --manifest-path rust/rustgram/Cargo.toml --features gui --bin rustgram-gui
```

Реализованы вход, постраничная загрузка диалогов, история выбранного чата
и отправка текста. История показывается страницами до 50 сообщений: можно
перейти к более ранним или вернуться к последним. Названия загруженных чатов
сохраняются в памяти до завершения сеанса. Черновики хранятся только в памяти
до закрытия окна. При неподтверждённой отправке текст сохраняется; после сообщения об ошибке
приложение не запускает новую отправку самостоятельно. Библиотека может
повторять запрос до завершения вызова по своей политике; перед ручным повтором
проверьте историю чата.
Последняя страница открытого чата обновляется при событиях новых, изменённых
и удалённых сообщений; доступна и кнопка ручного обновления. При просмотре
старой страницы новые события не переключают её, а показывают уведомление.
Используется восстановление пропущенных событий библиотеки, но его работа в реальном аккаунте, включая
разрывы связи и возобновление сессии, ещё не проверена. Список чатов пока не
обновляется автоматически; медиа и перенос сессии Forkgram ещё не реализованы.
Авторизация, история и отправка в реальном аккаунте не проверялись.

Проверка окна с локальным фиктивным чатом и синтетическим событием без входа
в Telegram (нужны Xvfb, `xauth`, `dbus-run-session`, Python и библиотеки X11/XTest):

```sh
cargo build --manifest-path rust/rustgram/Cargo.toml --features gui --example gui-fixture
xvfb-run -a -s '-screen 0 1200x800x24' dbus-run-session -- \
  python3 rust/rustgram/tests/support/drive_gui_fixture.py \
  rust/rustgram/target/debug/examples/gui-fixture
```

# rustgram: ранний экспериментальный клиент

Отдельная основа нового клиента на Rust. Сейчас реализованы вход по номеру,
коду и при необходимости двухэтапному паролю, вывод до 20 чатов и чтение
последних сообщений выбранного чата. Это не
готовая замена Forkgram: GUI, отправка сообщений, вложения и другие функции отсутствуют,
а реальный вход и взаимодействие с Telegram ещё не проверены.

Telegram API и MTProto предоставляет `grammers` на Rust. Для сохранения сессии
используется SQLite через `libsql`, который включает нативную библиотеку на C;
проект пока не состоит исключительно из Rust-кода.

## Запуск

Нужны собственные Telegram API ID и API hash (см.
[Telegram API development tools](https://core.telegram.org/api/obtaining_api_id)).
Передайте их через переменные `RUSTGRAM_API_ID` и `RUSTGRAM_API_HASH`, затем:

```sh
cargo run --manifest-path rust/rustgram/Cargo.toml -- dialogs
cargo run --manifest-path rust/rustgram/Cargo.toml -- history CHAT_ID 20
```

`CHAT_ID` берётся из списка диалогов; лимит истории от 1 до 100.
Сообщения выводятся в терминал, поэтому они могут сохраниться в его истории.

Вводите номер, код и пароль только в терминале программы, никому их не
передавайте. Создаётся новая авторизованная сессия Telegram; Forkgram не
изменяется. Файл сессии расположен в `$XDG_DATA_HOME/rustgram/session.sqlite3`
или `~/.local/share/rustgram/session.sqlite3` и содержит данные доступа к
аккаунту без дополнительного шифрования. Программа требует закрытые права
каталога и файла; не делитесь ими и не добавляйте их в Git. Для отзыва доступа
используйте список активных сеансов Telegram. Удаление локальной копии файла
само по себе не отзывает удалённую авторизацию.

Офлайн-проверка: `cargo test --manifest-path rust/rustgram/Cargo.toml`.
